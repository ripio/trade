# WebSocket Checksum Hash - Rust Implementation

This is a Rust implementation of the WebSocket checksum hash algorithm for order book data.

## Requirements

- Rust 2021 edition or later
- Cargo

## Building

```bash
cargo build
```

## Running the Tests

```bash
cargo test
```

## Running the Example

```bash
cargo run
```

## Running with Docker

This implementation includes Docker support for easy testing in a containerized environment.

### Prerequisites

- Docker
- Docker Compose

### Running the tests with Docker

```bash
# Build and run the container
docker-compose up

# Or to run in detached mode
docker-compose up -d

# To stop the container if running in detached mode
docker-compose down
```

The Docker container will automatically build the project and run the tests when started.

## Usage

```rust
use websocket_checksum_hash::{get_orderbook_checksum, Order, Orderbook};

fn main() {
    // Create an orderbook
    let mut orderbook = Orderbook::default();
    
    // Add some asks
    orderbook.asks.push(Order { price: 0.3965, amount: 44149.815 });
    orderbook.asks.push(Order { price: 0.3967, amount: 16000.0 });
    
    // Add some bids
    orderbook.bids.push(Order { price: 0.396, amount: 51.0 });
    orderbook.bids.push(Order { price: 0.396, amount: 25.0 });
    orderbook.bids.push(Order { price: 0.3958, amount: 18570.0 });
    
    // Generate checksum
    let checksum = get_orderbook_checksum(&orderbook);
    println!("Checksum: {}", checksum);  // Output: 3802968298
}
```

## Implementation Details

The checksum is generated by:
1. Taking up to the top 10 bid and ask orders
2. For each price and amount:
   - Removing decimal points
   - Eliminating leading zeros
   - Concatenating the price and amount as a string
3. Aggregating the results for bids and asks
4. Calculating the CRC32 checksum of the combined string

The implementation uses the `crc32fast` crate for efficient CRC32 calculation.
