# WebSocket Checksum Hash - C++ Implementation

This is a C++ implementation of the WebSocket checksum hash algorithm for order book data.

## Requirements

- C++17 compatible compiler
- CMake 3.10 or higher

## Building

```bash
mkdir build
cd build
cmake ..
make
```

## Running the Tests

After building, run the tests with:

```bash
./test_checksum
```

## Running with Docker

This implementation includes Docker support for easy testing in a containerized environment.

### Prerequisites

- Docker
- Docker Compose

### Running the tests with Docker

```bash
# Build and run the container
docker-compose up

# Or to run in detached mode
docker-compose up -d

# To stop the container if running in detached mode
docker-compose down
```

The Docker container will automatically build the project and run the tests when started.

## Usage

```cpp
#include "checksum.cpp"
#include <iostream>

int main() {
    // Create an orderbook
    Orderbook orderbook;
    
    // Add some asks
    orderbook.asks.push_back({0.3965, 44149.815});
    orderbook.asks.push_back({0.3967, 16000});
    
    // Add some bids
    orderbook.bids.push_back({0.396, 51});
    orderbook.bids.push_back({0.396, 25});
    orderbook.bids.push_back({0.3958, 18570});
    
    // Generate checksum
    std::string checksum = getOrderbookChecksum(orderbook);
    std::cout << "Checksum: " << checksum << std::endl;  // Output: 3802968298
    
    return 0;
}
```

## Implementation Details

The checksum is generated by:
1. Taking up to the top 10 bid and ask orders
2. For each price and amount:
   - Removing decimal points
   - Eliminating leading zeros
   - Concatenating the price and amount as a string
3. Aggregating the results for bids and asks
4. Calculating the CRC32 checksum of the combined string

The implementation includes a custom CRC32 calculation function.
