# WebSocket Checksum Hash - PHP Implementation

This is a PHP implementation of the WebSocket checksum hash algorithm for order book data.

## Requirements

- PHP 7.4 or higher

## Usage

```php
<?php

require_once 'ChecksumHash.php';

// Example orderbook
$orderbook = [
    'asks' => [
        ['price' => 0.3965, 'amount' => 44149.815],
        ['price' => 0.3967, 'amount' => 16000],
    ],
    'bids' => [
        ['price' => 0.396, 'amount' => 51],
        ['price' => 0.396, 'amount' => 25],
        ['price' => 0.3958, 'amount' => 18570],
    ],
];

// Generate checksum
$checksum = ChecksumHash::getOrderbookChecksum($orderbook);
echo $checksum;  // Output: 3802968298
```


The Docker container will automatically run the tests when started.

## Implementation Details

The checksum is generated by:
1. Taking up to the top 10 bid and ask orders
2. For each price and amount:
   - Removing decimal points
   - Eliminating leading zeros
   - Concatenating the price and amount as a string
3. Aggregating the results for bids and asks
4. Calculating the CRC32 checksum of the combined string

PHP's built-in `crc32()` function is used for the checksum calculation, with special handling for negative values since PHP's `crc32()` can return negative integers.
