# WebSocket Checksum Hash - JavaScript Implementation

This is a JavaScript implementation of the WebSocket checksum hash algorithm for order book data.

## Requirements

- Node.js 14 or higher
- Yarn or npm

## Installation

```bash
# Using yarn
yarn install

# Using npm
npm install
```

## Usage

```javascript
const { getOrderbookChecksum } = require('./index.js');

// Example orderbook
const orderbook = {
  asks: [
    { price: 0.3965, amount: 44149.815 },
    { price: 0.3967, amount: 16000 },
  ],
  bids: [
    { price: 0.396, amount: 51 },
    { price: 0.396, amount: 25 },
    { price: 0.3958, amount: 18570 },
  ],
};

// Generate checksum
const checksum = getOrderbookChecksum(orderbook);
console.log(checksum);  // Output: 3802968298
```

```bash
docker-compose up

# Or to run in detached mode
docker-compose up -d

# To stop the container if running in detached mode
docker-compose down
```

The Docker container will automatically install dependencies and run the tests when started.

## Implementation Details

The checksum is generated by:
1. Taking up to the top 10 bid and ask orders
2. For each price and amount:
   - Removing decimal points
   - Eliminating leading zeros
   - Concatenating the price and amount as a string
3. Aggregating the results for bids and asks
4. Calculating the CRC32 checksum of the combined string

The implementation uses the `crc` npm package for CRC32 calculation.
