# WebSocket Checksum Hash - C# Implementation

This is a C# implementation of the WebSocket checksum hash algorithm for order book data.

## Requirements

- .NET 6.0 or higher

## Usage

```csharp
using System;
using System.Collections.Generic;
using WebSocketChecksumHash;

// Example orderbook
var orderbook = new Dictionary<string, List<Dictionary<string, object>>>();

// Create asks
var asks = new List<Dictionary<string, object>>();
asks.Add(new Dictionary<string, object> {
    { "price", 0.3965 },
    { "amount", 44149.815 }
});

// Create bids
var bids = new List<Dictionary<string, object>>();
bids.Add(new Dictionary<string, object> {
    { "price", 0.396 },
    { "amount", 51 }
});

orderbook.Add("asks", asks);
orderbook.Add("bids", bids);

// Generate checksum
string checksum = ChecksumHash.GetOrderbookChecksum(orderbook);
Console.WriteLine(checksum);  // Output: 3802968298
```

## Implementation Details

The checksum is generated by:
1. Taking up to the top 10 bid and ask orders
2. For each price and amount:
   - Removing decimal points
   - Eliminating leading zeros
   - Concatenating the price and amount as a string
3. Aggregating the results for bids and asks
4. Calculating the CRC32 checksum of the combined string

The implementation includes a custom CRC32 calculation since .NET doesn't provide a built-in CRC32 algorithm.
