# WebSocket Checksum Hash - Java Implementation

This is a Java implementation of the WebSocket checksum hash algorithm for order book data.

## Requirements

- Java 11 or higher
- Maven

## Usage

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

// Example orderbook
Map<String, List<Map<String, Object>>> orderbook = new HashMap<>();

// Create asks
List<Map<String, Object>> asks = new ArrayList<>();
Map<String, Object> ask = new HashMap<>();
ask.put("price", 0.3965);
ask.put("amount", 44149.815);
asks.add(ask);

// Create bids
List<Map<String, Object>> bids = new ArrayList<>();
Map<String, Object> bid = new HashMap<>();
bid.put("price", 0.396);
bid.put("amount", 51);
bids.add(bid);

orderbook.put("asks", asks);
orderbook.put("bids", bids);

// Generate checksum
String checksum = ChecksumHash.getOrderbookChecksum(orderbook);
System.out.println(checksum);  // Output: 3802968298
```


## Running with Docker

This implementation includes Docker support for easy testing in a containerized environment.

### Prerequisites

- Docker
- Docker Compose

### Running the tests with Docker

```bash
# Build and run the container
docker-compose up

# Or to run in detached mode
docker-compose up -d

# To stop the container if running in detached mode
docker-compose down
```

The Docker container will automatically compile the code and run the tests when started.

## Implementation Details

The checksum is generated by:
1. Taking up to the top 10 bid and ask orders
2. For each price and amount:
   - Removing decimal points
   - Eliminating leading zeros
   - Concatenating the price and amount as a string
3. Aggregating the results for bids and asks
4. Calculating the CRC32 checksum of the combined string
